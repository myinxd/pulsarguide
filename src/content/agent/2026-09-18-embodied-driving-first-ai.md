> 2025 年中国人形机器人出货 1.44 万台，占全球 84.7%；2026 年上半年，具身智能和机器人赛道融了 460 亿元、288 起。
> 同一时间，你车里的辅助驾驶已经跑了几年，每天在真实道路上处理加塞、鬼探头和暴雨。
> 前者的新闻密度是后者的十倍。但论「在物理世界里活下去」的经验，两者差着一个数量级。

这就是我想开这个专栏的理由：**具身智能不缺信息，缺参照系。**

新闻里每天都在发生「突破」，可哪些是真突破、哪些是换了名字的老问题、哪些在自动驾驶领域早就被证伪过——没有参照系就没法判断。而这个参照系，恰好你已经有了。

## 一、具身智能到底是什么

先把定义钉住，省得后面被各种缩写带跑。

**具身智能（Embodied AI）是指智能体通过物理本体与环境实时交互，完成「感知—认知—决策—行动」闭环的系统。** 关键词是**闭环**，而且必须是和物理世界闭合的。

这个定义直接划出了它和大语言模型的分界线。LLM 的世界里，一次输出错误，删掉重来就行；具身智能的世界里，一个错误动作会改变环境状态，而环境不会 reset。三条区别值得记牢：

| | 大语言模型 | 具身智能 |
|---|---|---|
| 环境 | 静态、可重置 | **动态、不可逆** |
| 观测 | 完整上下文 | **部分可观测，传感器有噪声** |
| 错误代价 | 重写一次回复 | **可能撞上东西** |
| 数据 | 互联网上现成的 | **必须自己采，采一条少一条** |
| 时间预算 | 秒级可以接受 | **控制回路要求毫秒到几十毫秒** |

最后两行是核心矛盾。语言模型的 Scaling Law 能成立，是因为互联网上有一辈子读不完的文本。物理世界里没有这种现成数据——你要么让人戴动捕手套一条条遥操作（一天只有 100–150 条），要么想办法从仿真和人类视频里变出数据来。这构成了这个领域最硬的约束，也是后面几篇会反复回到的主题。

## 二、为什么用驾驶当参照系

因为**自动驾驶是唯一已经规模化部署、并且每天都在真实物理世界里接受检验的具身智能系统。**

而且它踩过的坑，机器人正在一个个重新踩：

- **数据闭环**：AD 行业十年前就在做「路测 → 挖掘 corner case → 回灌训练」的数据飞轮。机器人行业现在才开始建数采工厂，本质上是在抄同一套作业。你分析 preprocess.py 时关心的那些样本筛选和标签一致性逻辑，机器人团队会一个字不差地遇到。
- **端到端 vs 模块化**：AD 圈的「感知→预测→规划」模块化流水线之争，机器人圈叫「传统分层控制 vs VLA 端到端」。争论的措辞不同，结论会一样——模块化保住可验证性，端到端换来泛化，最后大概率是双系统共存。
- **仿真与 sim2real**：AD 靠仿真跑长尾，机器人靠仿真补接触动力学。都用仿真，都受同一个 gap 的折磨。
- **安全论证**：AD 有一整套「如何证明这个系统不会杀人」的方法论（安全边界、极小概率事件、失效降级）。人形机器人一旦进家庭和工厂，这套东西会直接搬过去。

所以在这个专栏里，**自动驾驶不是配角，它是已经跑完一轮的压力测试。**

反过来也有价值：机器人圈正在发生的 VLA、语言引导、跨本体泛化，恰好是自动驾驶下一步要吸收的东西。语言模型的常识、自然语言指挥、跨平台复用同一套大脑——这些能力 AD 还没有，而机器人领域已经在实证了。

这就是专栏的两条腿：**用驾驶解释机器人，用机器人反观驾驶。**

## 三、术语地图

后面会反复出现这些词，先给一张能贴在手边的对照表。

| 术语 | 一句话解释 |
|---|---|
| **VLA** | Vision-Language-Action 模型：输入像素加文字指令，直接输出动作信号。当前主流范式 |
| **World Model** | 世界模型：预测「做了之后会发生什么」，让机器人在内部先「想象」动作后果再执行 |
| **WAM** | World Action Model：把世界模型的预测能力和动作执行放进同一个模型体系，2026 年下半年的融合方向 |
| **双系统 / S1-S2** | 借鉴卡尼曼的「快慢思考」：S2 大脑是慢而聪明的 VLM 负责规划，S1 小脑是高频策略负责平衡和精细动作 |
| **遥操作** | Teleoperation，人戴设备操作机器人采集数据，是当前真机数据的主要来源 |
| **Cross-embodiment** | 跨本体：同一个模型驱动不同形态的机器人（不同臂长、不同夹爪、甚至人形） |
| **sim2real** | 仿真训练、真机部署之间的能力落差，通常表现为接触、形变、材质上的失效 |
| **物理 Token 经济学** | 按「机器人干了多少活」计费，而不是按订阅或按整机售卖 |
| **捷径学习** | Shortcut learning：模型没有学到真正的物理规律，而是抓住了数据集里的统计相关性 |

一个提醒：**VLA 与世界模型的路线之争在 2026 年已经收口了。** 智源大会上给出的判断是——世界模型不是 VLA 的竞争路线，而是 VLA 体系的核心组成部分。后面第二篇会细说这场争论是怎么结束的。

## 四、专栏路线

首季六篇，两条线交替：**一条讲模型怎么想，一条讲数据从哪来。**

1. **开篇：驾驶是第一个具身智能**（你正在读）
2. **路线图：VLA、世界模型与 WAM** —— 三条路线如何收敛，以及 π0.7 那份「机器人界的 GPT-3 时刻」报告该怎么读
3. **双系统：大脑与小脑的分工** —— Helix / GR00T / Gemini Robotics 共同押注的范式，为什么这个妥协是最优解
4. **数据瓶颈：遥操一天只有 150 条** —— 合成数据、人类视频、真机回流三种解法的真实成本
5. **泛化为什么这么难** —— VLA 被质疑「捷径学习」的物理原因，以及「是真泛化还是在检索相似样本」这个无法回避的评估困境
6. **物理 Token 经济学** —— 机器人怎么计费，以及为什么这门生意和 API 计费的结构完全不同

## 五、和既有内容的呼应

这个专栏会顺着已有的两条线长出来。

一条是 [DINOv3 端到端驾驶系列](/blog/series/dinov3-e2e-ad/)：那个系列讲的是「用一个冻结的视觉编码器替掉整个感知栈」，本质上是一次具身智能的端到端实验。里面关于纹理抑制、运动盲区、时序聚合的讨论，在机器人的操作任务里会以「接触动力学」和「形变物体」的形式重新出现。

另一条是 [agent 专栏](/agent/)：具身智能的「大脑」正在复刻大模型圈的每一条曲线——提示工程、context 管理、模型固化进协议、算力账本。第三篇讲双系统的时候，我会把这个问题正面摊开：**机器人上的「壳」和「模型」，谁更值钱。**

最后留一句我的判断，也是这个专栏的立场：

> 具身智能现在的热度，主要来自「人形」这个形态，而不是「智能」这个能力。
> 形态的收敛会比很多人预想的快，能力的爬坡会比很多人预想的慢。盯住能力那条线，噪音会少很多。
